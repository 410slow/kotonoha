KOTONOHA v0.8 처음 실행 방법

1. 이 압축을 풉니다.
2. VS Code를 엽니다.
3. File → Open Folder를 누릅니다.
4. KOTONOHA-v0.8 폴더를 선택합니다.
5. 상단 메뉴에서 Terminal → New Terminal을 누릅니다.
6. 아래 명령어를 입력합니다.

npm install

7. 설치가 끝나면 아래 명령어를 입력합니다.

npm run dev

8. 터미널에 나오는 http://localhost:5173 주소를 클릭합니다.

중요
- 예전 kotonoha-v0.1 폴더 안에 복사하거나 붙여넣지 않습니다.
- KOTONOHA-v0.8 폴더를 통째로 새 프로젝트처럼 엽니다.
- Firebase 설정은 이미 포함되어 있어 .env 파일을 만들 필요가 없습니다.
