# KOTONOHA v0.9

실질적인 첫 번째 '오늘의 레슨' 버전입니다.

## 새 기능
- 오늘의 레슨 중심 홈
- 사토 선생님 레슨 화면
- 일본어 직접 입력 문제
- 문장 자동 채점
- 오답 부분 표시
- 힌트
- 받아쓰기
- 체크리스트 대신 문제형 숙제
- 숙제 자동 채점
- 오답노트 자동 저장
- 다음 Day 자동 증가
- 기존 Firebase 학습자 데이터 호환

## 실행
```bash
npm install
npm run dev
```

## 🎮 균승이 개패기 (미니게임)

`game/` 폴더에 들어 있는 1인칭 잠입 게임입니다. 균승이가 자기 방에서 먹방을 찍는 동안 현관에서 출발해 **소리 안 나게** 다가가 한 대 때리고 **현관까지 돌아오면** 성공. 무궁화꽃이 피었습니다 규칙으로, 균승이가 고개를 들 때 움직이면 들킵니다.

- 실행: `npm run dev` 후 **http://localhost:5173/game/index.html** (빌드 없이 `game/` 폴더만 아무 정적 서버에 올려도 됩니다)
- 조작 (폰): 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 둘러보기, `살금` 토글, `달리기` 꾹, 균승이 옆에서 `때리기`
- 조작 (PC): `WASD` 이동, 마우스 둘러보기(클릭하면 포인터 잠금), `Shift` 살금, `Space` 달리기, `E`/클릭 때리기
- 집: 현관 · 거실 · 주방 · 북서 복도(화장실·세탁실) · 균승이 방. 바닥의 치킨 박스/피자 박스/캔/배달봉지/컵라면을 밟으면 소리가 나고, 문턱 근처 마루는 밟으면 삐걱거립니다.
- 균승이: 실제 사진 스프라이트(먹는 중 / 폰 보는 중 / 고개 듦 / 맞음 / 엥마). 추격할 때는 전신 사진을 머리·몸통·팔·허벅지·정강이로 나눈 종이인형 리그(`game/assets/rig_*.png`, `rig.json`)가 다리와 팔을 번갈아 움직이며 걸어옵니다. 고개 들기 직전에 젓가락 소리 + `…` 표시가 뜹니다. 소음이 쌓이면 바로 돌아봅니다.
- 맞으면 휘청 + 뺨 자국 + 별, 그 뒤 **"엥마~"** 하고 일어나 쫓아옵니다. 잡히면 **"엥마! 잡았지롱~"**.
- 난이도(쉬움/보통/어려움)는 추격 속도, 돌아보는 빈도, 소음 민감도, 쓰레기 개수를 바꿉니다.
- 기록: 성공한 판만 아이디·난이도·걸린 시간이 저장되고 게임이 끝나면 순위표가 뜹니다. 기본은 기기(localStorage) 저장.
- 친구들과 기록 공유: `game/firebase-config.example.js` 를 `game/firebase-config.js` 로 복사해 Firebase 웹 설정을 넣고, `firestore.rules` 를 배포하면 Firestore `engma_records` 컬렉션에 공유 저장됩니다.
- 친구 실제 목소리: `game/voice/engma.mp3` 를 넣으면 TTS 대신 재생됩니다 (`game/voice/README.md`).
- 얼굴 교체: `game/assets/friend_*.png` (배경 제거된 PNG) 를 바꾸면 됩니다. 걷는 리그는 전신 사진 하나를 관절별로 잘라 `rig.json`에 피벗 좌표를 적어 만듭니다.
- 방/집 사진으로 더 현실감 있게 만들고 싶으면 균승이 집 사진(벽, 바닥, 책상 주변)을 보내 주세요. 텍스처로 입힐 수 있습니다.

### 카톡으로 공유하기 (로그인 없이 링크만 열면 바로 플레이)

게임은 `game/` 폴더 하나로 완결된 정적 페이지라서 아무 https 호스팅에나 올리면 됩니다. 두 가지 방법을 준비해 두었습니다.

1. **GitHub Pages** (`.github/workflows/pages.yml`)
   - 저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 설정합니다.
   - `main` 에 머지하거나 Actions 탭에서 워크플로를 수동 실행(Run workflow)하면
     **https://410slow.github.io/kotonoha/** 주소가 생깁니다. 이 링크를 카톡방에 올리면 끝.
   - 주의: 무료 계정은 **공개(public) 저장소**에서만 Pages 가 동작합니다. 비공개로 두려면 아래 2번을 쓰세요.
2. **Firebase Hosting** (`firebase.json`, 이미 쓰는 Firebase 프로젝트 재사용)
   ```bash
   npx firebase-tools login
   npx firebase-tools use <파이어베이스-프로젝트-ID>
   npx firebase-tools deploy --only hosting
   ```
   출력되는 `https://<프로젝트>.web.app` 링크를 공유하면 됩니다.

링크를 연 사람은 로그인 없이 바로 게임이 시작됩니다. 친구 얼굴 사진도 함께 공개되는 링크이니 친구 동의는 받아 두세요.
