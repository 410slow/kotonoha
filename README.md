# KOTONOHA v0.8

이번 버전부터는 패치 파일이 아니라 전체 프로젝트로 제공합니다.

## 포함된 기능

- Firebase 회원가입·로그인
- Firestore 사용자별 학습 기록 저장
- 최초 일본어 레벨 진단
- 홈 대시보드
- 히라가나·가타카나 문자 숙련도
- 단원형 학습 화면
- 문자·단어·표현·듣기·평가 흐름
- 숙제 생성과 확인
- 취약 문자 복습
- 개발자 미리보기 모드
- 모든 문자 단원과 수업 단계 자유 확인
- 모바일 반응형 UI

## 실행

```bash
npm install
npm run dev
```

Firebase 설정은 이미 포함되어 있으므로 `.env` 파일이 필요하지 않습니다.
