# 친구 목소리 넣는 곳

이 폴더에 아래 이름으로 음성 파일을 넣으면 게임이 TTS 대신 실제 목소리를 재생합니다.

| 파일명 | 언제 재생 |
|---|---|
| `engma.mp3` | 내가 친구를 때렸을 때 ("엥마~") |
| `engma_catch.mp3` | 친구가 나를 잡았을 때 ("엥마!") — 없으면 `engma.mp3`를 대신 씀 |

- 인스타그램 릴스/스토리에서 "엥마" 하는 부분만 잘라서 mp3(또는 m4a)로 저장하면 됩니다.
- 파일이 없으면 브라우저 한국어 음성 합성(TTS)으로 높고 얄미운 톤의 "엥마~"가 나옵니다.
- mp4 영상에서 소리만 뽑기: `ffmpeg -i clip.mp4 -ss 0:03 -t 1.2 -vn engma.mp3`
